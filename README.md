# NEET Girl Date Night: Random Dialogue Generator Mod
<img src="https://github.com/user-attachments/assets/8638ce84-e562-45f8-8163-eb35cde64a74" width="1000"/>

# What is this mod?
This is a mod for a game called "NEET Girl Date Night" that allows you to generate dialogues and replace the game's original dialogues with the generated dialogues.

# Setup
You need to have the "NEET Girl Date Night" game (which can be downloaded from https://hitsujigoods.itch.io/ngdn).
### For Windows:
1) Click on 'Releases' and look for a release that has a text "Latest" written in green near the title.
<img border="1px solid black" src="https://github.com/user-attachments/assets/53f36cce-d7b4-4d71-9efb-a4d637e32590" width="1000"/>
<img src="https://github.com/user-attachments/assets/2578faac-482b-4ab0-bad4-f221dff51266" width="1000"/>

2) On that release, click on Source code (zip) or Source code (tar.gz) to download it.
<p align="center"><img src="https://github.com/user-attachments/assets/14f7ad5e-2eeb-4ed3-b093-62c2ab92941a" width="1000"/></p>

3) Once you have downloaded it, Right click on zip file and extract it.
<p align="center">
  <img src="https://github.com/user-attachments/assets/7bfdf5a7-5389-45c7-8865-e63b0fcc8d1a" width="400" height="350"/>

</p>
<p align="center"><img src="https://github.com/user-attachments/assets/247beca1-5a94-4096-97ee-6781b0bb8ac0" width="400"/></p>


4) Go inside the folder, then go inside the 'build-version-for-windows' folder.
<p align="center">
  <img src="https://github.com/user-attachments/assets/24fa091c-c59e-4ab0-8004-233a0149d30f" width="400" height="300"/>
  <img src="https://github.com/user-attachments/assets/1623e1ac-24f0-4eca-800d-a49945069424" width="400" height="300"/>
</p>
<p align="center"><img src="https://github.com/user-attachments/assets/08e0b20b-7911-49de-aac7-695ada2721e9" width="500"/></p>


5) Select the file 'NGDN_RDGM.exe' and the folder named 'assets' from the 'build-version-for-windows' folder, and then drag them into the 'NEET_Girl_Date_Night-1.1-win' folder.
<img src="https://github.com/user-attachments/assets/b3d5d614-b9dc-4039-850b-b39f7f017af7" width="1000"/>
<img src="https://github.com/user-attachments/assets/27f71534-dee2-4a79-8b08-0c3ff9cf6cd5" width="1000"/>


6) Then run the 'NGDN_RDGM.exe' file.
<img src="https://github.com/user-attachments/assets/17abe244-3b5b-40ea-9c0e-d704cbc727ab" width="1000"/>


7) When you run the application, Windows SmartScreen may appear due to a lack of users running the application and because the application has an unknown publisher according to Microsoft. Press 'More info' and then 'Run anyway'.

8) Celebrate! 🥳
